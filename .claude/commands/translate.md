# 全語系翻譯

自動判斷來源語言與目標語言，套用最適合的翻譯策略。

## 使用方式

```
/translate [文字或檔案內容]
```

快速指令（加在內容前）：
- `全語言 [文字]` → 同時輸出 10 種語言
- `正式版 [文字]` → 強制正式書面語氣
- `口語版 [文字]` → 強制口語輕鬆語氣
- `對照版 [文字]` → 原文與譯文逐句對照
- `回譯檢查 [譯文] | [原文]` → 回譯驗證準確度

## 自動判斷邏輯

1. 未指定目標語言 → 繁中輸入譯英文；英文輸入譯繁中（台灣）
2. 未指定風格 → 依內容類型自動選擇
3. 混合語言輸入 → 翻成主要目標語言，保留必要專有名詞
4. 單一詞彙 → 給出詞義、多種翻法、例句

## 內容類型對應策略

| 類型 | 策略 |
|------|------|
| 技術文件 / IT | 保留術語原文（加括號說明），精確為主 |
| 法律合約 | 字字精準，保留法律結構 |
| 行銷文案 | 意譯為主，保留情感張力 |
| 影視字幕 | 口語化，字數精簡 |
| 程式碼註解 | 保留技術術語，說明清晰 |

## 輸出格式

**標準翻譯**
```
【翻譯結果】
（翻譯內容）

【語言】來源語言 → 目標語言
【類型】偵測到的內容類型
```

**多語言輸出**（`全語言` 指令）
```
🇹🇼 繁中：...
🇺🇸 英文：...
🇯🇵 日文：...
🇰🇷 韓文：...
🇪🇸 西班牙文：...
🇫🇷 法文：...
🇩🇪 德文：...
🇧🇷 葡文：...
🇮🇳 印地文：...
🇸🇦 阿拉伯文：...
```

## 台灣繁中用詞規範

- 用：軟體 / 網路 / 資訊 / 檔案 / 應用程式
- 不用：軟件 / 網絡 / 信息 / 文件 / App（直接用英文或台灣說法）
