# 演算法生成藝術

用 p5.js 建立互動式生成藝術 HTML Artifact，內建種子控制與參數滑桿。

## 使用方式

```
/art [描述想要的藝術風格或主題]
```

範例：
- `/art 流動的粒子系統，像水墨在水中暈散`
- `/art 幾何分形，蕨類植物的形狀`
- `/art 流場可視化，像風的流動`
- `/art 互動式波形，滑鼠移動影響波形`

## 執行流程

1. **演算法哲學**：建立 4-6 段的創作哲學宣言，為這個生成藝術命名一個藝術運動（如「有機渦流」「量子噪聲」）
2. **概念萃取**：找出請求中的隱藏概念核心
3. **p5.js 實作**：建立完整的互動式 HTML 檔案
4. **種子系統**：加入上一個/下一個/隨機/指定種子控制
5. **參數控制**：加入 2-4 個可調整的滑桿（速度、密度、色彩等）

## 技術規範

```html
<!-- 依賴 -->
<script src="https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.7.0/p5.min.js"></script>

<!-- 必要設定 -->
randomSeed(seed);   // 確保可重現
noiseSeed(seed);    // 噪聲也要 seed
```

## 輸出

- 單一自包含 `art.html` 檔案
- 包含：畫布 + 種子控制器 + 參數滑桿 + 藝術家說明
- 可直接在瀏覽器開啟，按 Space 切換新種子，S 儲存截圖

## 色彩與構圖原則

- 色彩搭配要有大師級工藝感（Coolors、Adobe Color 啟發）
- 構圖遵循黃金比例或三分法
- 動畫流暢（60fps 目標），避免跳幀
